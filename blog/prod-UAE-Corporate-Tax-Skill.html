The Problem

UAE companies must register for Corporate Tax within 3 months of incorporation, with a late-registration penalty of AED 10,000. Engaging agents or consultants costs AED 1,000–1,500 to complete a single form on the FTA's EmaraTax portal. This repo provides a skill to let AI agents automate that form-filling, potentially eliminating the fee entirely.

What This Does

The repository contains a skill for AI agents to automate UAE Corporate Tax registration on EmaraTax. SKILL.md is the core skill file, containing step-by-step instructions the agent follows across five stages: creating the Taxable Person profile, entering entity and licence details, business activities, owner and authorised signatory information, and the contact block. Supporting documentation lives in references/: before-you-start.md lists required documents (trade licence, certificate of incorporation, MOA, Emirates ID and passport of owner and signatory), while emaratax-walkthrough.md provides field-by-field details for all five steps. gotchas.md (referenced but truncated in the excerpt) likely documents edge cases. The skill handles problematic elements like the SAP file uploader that silently drops files, the mandatory landline field, Emirates ID validation, and the auto-calculated first tax period, but stops before the final legal declaration so the user reviews and submits manually.

How It Is Wired

Execution starts when the user points their AI agent at SKILL.md—in Claude Code this means dropping the folder into the skills directory, or alternatively pasting SKILL.md contents into the chat and saying "help me register for UAE Corporate Tax on EmaraTax, I'm logged in." The skill then guides the agent through five sequential steps by asking questions and validating inputs against the user's documents. It touches the EmaraTax portal browser interface for form filling and document uploads, but does not handle authentication (the user logs in themselves), OTP entry, or the final legal declaration submission. The call graph is straightforward: agent → SKILL.md instructions → EmaraTax portal interactions → user review at the final step. No external database, network persistence, or filesystem writes beyond temporary document staging appear in the described flow. The repository contains no source code files with executable logic; the "skill" is entirely natural language instructions for an external AI agent rather than runnable code with dependencies, imports, or a runtime environment.

How To Use It

Setup requires an AI agent capable of browser control (Claude Code with browser/tools, OpenAI Codex, or equivalent), an EmaraTax account (free at eservices.tax.gov.ae), and prepared documents as PDFs per references/before-you-start.md. Configuration is minimal: no environment variables or keys are needed beyond the user's EmaraTax login credentials, which the agent never requests. To run it, the user opens EmaraTax in the browser, logs in, then points the agent at SKILL.md—either by dropping the folder into Claude Code's skills directory or pasting the skill contents into the chat and saying "help me register for UAE Corporate Tax on EmaraTax, I'm logged in." The agent works through the prompts, pulling data from the provided documents and asking for any missing fields (such as mobile number). At the end, the user reads the review screen, ticks the declaration, and submits themselves.

Real-World Use

A UAE free zone company incorporating on March 1 must register for Corporate Tax by June 1 to avoid the AED 10,000 penalty. The owner gathers trade licence, certificate of incorporation, MOA, and Emirates ID + passport PDFs. Using Claude Code, they drop the repo folder into their skills directory and invoke the skill. The agent walks them through EmaraTax step-by-step, validating the SAP upload by requiring the user to re-select files if the initial upload appears to fail, filling the landline field with the company's contact number, and validating Emirates ID format. After the agent populates all five steps, the owner reviews the auto-calculated first tax period and TRN application details, ticks the declaration, and submits. Approval comes within 5–20 business days (the author's came through the same day with a TRN).

The Bottom Line

This is a focused, practical automation skill that delivers on its promise: it walks an AI agent through the EmaraTax Corporate Tax registration form, handles the fiddly UI elements that typically trip people up, and stops before the final declaration so the user maintains control. There's real value here for UAE companies needing to register without paying agent fees, provided they have an AI agent with browser control and their documents ready. The main limitation is the dependency on a specific agent platform's browser/computer tooling, and the entire operation hinges on the user's willingness to review each step's output. It's not tax advice, but as an automation helper it's credible, well-documented, and worth running for any UAE company facing the 3-month registration deadline.
